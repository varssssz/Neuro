# Experimental_Results/ — original, unrounded CSV outputs

These are the literal CSV files written by `Source_Code/run_all.py` (full clean run, `results_full/`), **not** rounded or re-derived summaries. Every number in the manuscript's tables and the text was read from these files (see `Reproducibility/METHODOLOGY.md` for how). All 20 directed transitions, all 18 non-control + 2 control transitions, every requested item below is in here.

## File-by-file

- **`transitions_main.csv`** — THE primary results table. One row per directed transition (20 rows = 5 pipelines × 4 others). Columns include: `src,tgt,qc_level,N`, `cov_src/raw/std/src_site/sitestd/wcp/wcp_reg` (coverage under each condition), `cov_*_lo/hi` (bootstrap 95% CI), `d_raw/d_std/d_sitestd` + `_lo/_hi` (paired coverage differences from source, with bootstrap CI), `mcnemar_p_raw/std` (exact McNemar p-values, seed 0, **uncorrected** — see Literature_Review/ or manuscript for the Bonferroni comparison computed separately), `width_src`, `width_src_site`, `wcp_frac_inf`, `wcp_reg_frac_inf` (fraction of infinite intervals), `wcp_median_width`, `wcp_reg_median_width`, `wcp_cov_if_finite`, `wcp_reg_cov_if_finite`, `cov_{src,raw,std}_seed_sd` (across-seed SD), `frac_fold_below_088_{src,raw,std}` (noise-floor diagnostic), `MAE_{src,raw,std,sitestd}`, `mean_offset_mm`, `sd_ratio`, `mean_feature_r` (feature-level shift diagnostics), `control` (True for the FS6.0↔FS5.3 pair).
- **`per_subject_main.csv`** — per-subject, per-transition coverage indicators (16,718 data rows): `src,tgt,sid,site,age,dx,cov_src,cov_raw,cov_std,cov_src_site,cov_sitestd,cov_wcp,cov_wcp_reg`. This is the row-level data the paired bootstrap, McNemar test and age/diagnosis strata are computed from.
- **`strata_main.csv`** — age-bin and diagnosis-stratified coverage (560 rows): `src,tgt,stratum,n,cond,cov,lo,hi` (Wilson CI). Strata: `<12,12-15,15-18,18-25,>=25,ASD,TD`. Strata with n<20 are dropped by the script (not present as blank rows — true absence).
- **`recal_main.csv`** — ReForm-style recalibration curve (200 rows = 20 transitions × 5 k-values × 2 variants): `src,tgt,variant(reform_raw|std_then_reform),k,mean_cov,cov_lo,cov_hi,frac_below_088,mean_width,n_draws`. `n_draws`=2500 (5 folds × 5 seeds × 100 resamples) per cell.
- **`transitions_atlas.csv`** / no separate per-subject file beyond `per_subject_atlas.csv` — the 6-row atlas-confound arm (FS60DK↔FS60, FS60DK↔FS53, FS60DK↔FS51 and reverses), same columns as `transitions_main.csv` minus the wcp/reform/site extras (`extras=False` in that stage).
- **`transitions_qc0.csv`, `transitions_qc2.csv`** — the same 20 transitions re-run at QC0 (no exclusions) and QC2 (stringent) levels, for the QC-sensitivity analysis. Same column set as `transitions_atlas.csv`.
- **`per_subject_atlas.csv`, `per_subject_qc0.csv`, `per_subject_qc2.csv`** — per-subject coverage for those three sensitivity arms.
- **`lgbm.csv`** — LightGBM robustness check, all 20 transitions, seeds {0,1,2}: `src,tgt,N,lgbm_cov_src,lgbm_cov_raw,lgbm_cov_std,lgbm_d_raw,lgbm_d_raw_lo,lgbm_d_raw_hi,lgbm_d_std,lgbm_d_std_lo,lgbm_d_std_hi`.
- **`monitors_b25.csv`, `monitors_b50.csv`, `monitors_b100.csv`** — label-free shift-monitor results at batch sizes 25/50/100: `src,tgt,N,batch,mmd_raw_far_test,mmd_raw_detect,ks_raw_far_test,ks_raw_detect,mmd_std_far_test,mmd_std_detect,ks_std_far_test,ks_std_detect`. `*_far_test` = observed false-alarm rate on source test batches (should be ≈0.05 by construction of the threshold); `*_detect` = detection rate on target-pipeline batches.
- **`mixed_pipeline.csv`** — mixed-pipeline training arm (5 rows, one per target pipeline, N=669 subjects with all 5 pipelines): `target,N,within,xfer_raw_mean,xfer_raw_min,xfer_std_mean,mix_all,mix_loo,width_all,width_loo,MAE_all,MAE_loo,mix_all_lo/hi,mix_loo_lo/hi`.
- **`loso_by_site.csv`** — leave-one-site-out, per held-out site per transition (120 rows = 20 transitions × 6 sites): `src,tgt,heldout,n,cov_src,cov_raw,cov_std,cov_src_site,cov_sitestd`.
- **`loso_pooled.csv`** — LOSO pooled across the 6 sites per transition (20 rows): `src,tgt,n_total,cov_src,cov_raw,cov_std,cov_src_site,cov_sitestd,min_site_cov_raw,min_site_cov_std`.
- **`matched_N_by_site.csv`**, **`matched_N_summary.csv`** — matched sample sizes per pipeline pair per QC level, overall and by site.
- **`run_log.txt`** — literal stdout/log of the final full run (`[main] FS51->FS53 N=859 src=0.905 raw=0.807 std=0.884 (…s)` etc. for every stage); this is the closest thing to an execution trace/timing record that exists.

## What counts as "failed, excluded, or inconclusive"

- No transition, seed, or fold silently failed or was dropped from the reported tables — all 20×5(or 3) combinations that were attempted appear in every applicable table.
- The only systematic "near-failure" is **weighted conformal prediction**, which is not excluded but is reported as largely uninformative: `wcp_frac_inf`/`wcp_reg_frac_inf` in `transitions_main.csv` show 77–100% infinite intervals for every cross-software transition (see column values directly). This is a genuine negative result, kept in the data, not hidden.
- Strata with n<20 (mostly the oldest age bin for smaller transitions, or diagnosis splits in low-N pairs) are simply absent from `strata_main.csv` — there is no placeholder row; check `n` per `(src,tgt,stratum)` combination to see what was excluded from stratified reporting.
