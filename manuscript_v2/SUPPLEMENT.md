# Supplementary material — "Same scan, different pipeline" (v2)

Each item points to the file that contains it. All paths are relative to the repository root.

## S1. Supplementary methods
- **S1.1 Data flow and split integrity.** `AUDIT_BASELINE.md` §5–7, with tables `audit/phase1/out/split_integrity_by_fold.csv` and `audit/phase1/out/subject_roles_main_and_atlas_QC1.csv.gz`. The latter records each subject's role in every fold and seed.
- **S1.2 Feature schema and cross-pipeline feature alignment.** `audit/phase1/out/feature_schema_62.csv` and `audit/phase1/out/feature_alignment.csv`.
- **S1.3 Conformal ranks and the recalibration construction**, including the exact expected-coverage formula and automated tests: `RECALIBRATION_CORRECTION.md` §1–2 and `code_v2/tests/test_v2.py`.
- **S1.4 Inference design** (site clustering, CR1 test, Holm families, joint site bootstrap): `INFERENCE_AUDIT.md` §2.
- **S1.5 Adaptation taxonomy (classes A–D):** `STANDARDISATION_SENSITIVITY.md` §3.
- **S1.6 Drift-monitor specification:** `DRIFT_MONITOR_VALIDATION.md` §2.

## S3. Reproducibility statement
Every number in the main text is generated by `code_v2/build_numbers.py` into `manuscript_v2/numbers.json`, which records each value and its source file and column. The manuscript is rendered from the template by `code_v2/render_manuscript.py`, which fails on any unresolved placeholder. `RESULTS_CHANGELOG.md` lists every number that changed relative to the original manuscript.

To regenerate everything from the raw derivative tables at compare-surf-tools commit debcc78, run in order:
1. `code_v2/run_recalibration_v2.py`
2. `code_v2/run_frozen_v2.py`
3. `code_v2/run_secondary_textbook.py`
4. `code_v2/phase3_inference.py`
5. `code_v2/phase4_std_monitor.py`
6. `code_v2/phase5_age.py`
7. `code_v2/make_figs_v2.py`
8. `code_v2/build_numbers.py`
9. `code_v2/render_manuscript.py`

Total runtime is about 10 minutes on 2 CPU cores. The package versions are listed in `provenance/ENVIRONMENT.txt`. LightGBM could not be installed in the audit environment, so `lgbm.csv` is reported from the initial analysis.
